# Mon budget

PWA mobile-first de suivi de budget et d'audit d'abonnements.

- **100 % locale** : aucune donnée ne quitte le téléphone (stockage IndexedDB).
- **Zéro serveur** : site statique hébergé sur GitHub Pages.
- ⚠️ Ne jamais déposer de vrai relevé bancaire dans ce dépôt.

App en ligne : https://maiwennlrc.github.io/budget-app/

## Développement

```bash
npm install
npm run dev     # serveur local
npm run build   # version de production dans dist/
```
